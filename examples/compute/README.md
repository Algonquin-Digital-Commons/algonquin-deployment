# Synthetic Algonquin compute example

This example shows where institution-specific bindings live. It is an
illustrative candidate workload manifest, not a signed submission, approved
campus policy, real student record, lab inventory, or deployment configuration.
The `.example` domain, IDs, digest and signature value are synthetic.

The matching institution-neutral contract is owned by
[`psdc-architecture`](https://github.com/Post-Secondary-Digital-Commons/psdc-architecture/blob/main/contracts/compute/workload-manifest.schema.json).
Algonquin can select its own identity adapter, owner, campus zones and policy
values, but cannot silently weaken that Common contract. The Common v1 schema
is still a draft candidate; freeze and compatibility approval remain pending.

See [the example manifest](workload-manifest.algonquin.example.json) and the
[site-profile input register](../../docs/governance/Institution-Site-Profile-Input-Register.md)
for what still needs actual institutional approval.
